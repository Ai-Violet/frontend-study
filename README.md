## 🔧 站点引擎：数据驱动，新增课时零改动

整个站点的导航、侧边栏、翻页**全部由 `learn.js` 里的两个数组驱动**：

```javascript
// COURSE：课程结构 → 控制导航、抽屉、翻页
var COURSE = [
    { dir: "01-HTML基础", name: "HTML 基础", lessons: [...] },
    // ...
];

// RES_LESSON：扩展阅读 → 控制"扩展阅读"侧边栏
var RES_LESSON = {
    "05-Flex弹性布局.html": [
        { n: "MDN · Flexbox", u: "...", c: "#4A5568", t: "MDN" },
        // ...
    ],
    // ...
};
```

**新增一课时只需要**：
1. 在对应章节目录下创建 HTML
2. 往 `COURSE` 数组加一行
3. 往 `RES_LESSON` 加扩展阅读链接（可选）
4. `python build_search_index.py` 更新搜索索引

导航、侧边栏、上下课翻页、搜索索引**自动同步**——不需要改任何 HTML 模板。
