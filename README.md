## ✨ 核心交互：实时实验台

这是整个项目最特别的地方。每节课有 2-4 个这样的实验台：

```
┌─────────────────────────────────────────────────────┐
│ 把 .row 的 flex-direction 改成 column，两根轴立刻互换   │
├──────────────────────┬──────────────────────────────┤
│                      │                              │
│   代码编辑区           │       实时预览区              │
│   (textarea + 高亮)    │    (iframe，350ms 刷新)      │
│                      │                              │
│   你改这里 ──────────►│   立刻在这里看到变化            │
│                      │                              │
├──────────────────────┴──────────────────────────────┤
│  [HTML 预览] [CSS 样式.css]  ← 一个实验台可开多文件   │
└─────────────────────────────────────────────────────┘
```

实现原理很朴素：
1. `<script type="text/plain" class="lab-code">` 里放原始代码
2. textarea 负责编辑，overlay 负责语法高亮
3. 代码抽取后注入 iframe 的 `<style>` 标签
4. 改一行 → iframe 刷新 → 你立刻看到变化

**没有用 CodeMirror / Monaco / iframe 沙箱这些重量级方案**——够用就行。

## 🔧 站点引擎：数据驱动，新增课时零改动

整个站点的导航、侧边栏、翻页**全部由 `learn.js` 里的两个数组驱动**：

```javascript
// COURSE：课程结构 → 控制导航、抽屉、翻页
var COURSE = [
    { dir: "01-HTML基础", name: "HTML 基础", lessons: [...] },
    // ...
];

// RES_LESSON：扩展阅读 → 控制"扩展阅读"侧边栏
var RES_LESSON = {
    "05-Flex弹性布局.html": [
        { n: "MDN · Flexbox", u: "...", c: "#4A5568", t: "MDN" },
        // ...
    ],
    // ...
};
```

**新增一课时只需要**：
1. 在对应章节目录下创建 HTML
2. 往 `COURSE` 数组加一行
3. 往 `RES_LESSON` 加扩展阅读链接（可选）
4. `python build_search_index.py` 更新搜索索引

导航、侧边栏、上下课翻页、搜索索引**自动同步**——不需要改任何 HTML 模板。
