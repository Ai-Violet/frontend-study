# 🎯 前端自习室 · Frontend Study Room

> 从 HTML 标签到 CSS 动画，一课一实验，跟着改代码就能学会。

一个**面向前端初学者**的交互式学习网站。每节课不是"看文档背属性"，而是**左边学概念，右边直接改 CSS 看效果**——实时编辑器 + 即时预览，改一个像素就能看到变化。

---

## ✨ 特色

- 🧪 **实时实验台**：每节课内置 2-4 个可编辑的 CSS 实验，改代码立刻看效果
- 📖 **动手即学**：没有大段理论堆砌，边改边看边悟
- 📚 **4 章 29 课**：HTML 基础 → CSS 基础 → CSS 布局 → CSS3 进阶
- 🔍 **全站搜索**：一个字搜遍 29 节课的所有知识点
- 📱 **响应式**：手机、平板、桌面三端自适应
- 📚 **扩展阅读**：每节课侧边栏推荐 MDN / CSS-Tricks / 视频资源

## 🚀 快速开始

### 方式一：直接打开（最简单）

双击 `学习路线/教程中心页.html`，用浏览器打开即可。

> ⚠️ 注意：使用 `file://` 协议直接打开时，扩展阅读侧边栏和搜索索引正常工作；个别浏览器对跨文件 fetch 有限制，推荐用方式二。

### 方式二：本地服务器（推荐）

Windows 下一行命令启动：

```cmd
cd /d "d:\ProGramming\【我的前端学习】\2026新前端" && python -m http.server 8080
```

## 📂 项目结构

### 关键技术点

| 模块 | 技术 | 作用 |
|------|------|------|
| 实验台编辑器 | textarea + 透明 overlay + tokenize 高亮 | 实时编辑 + 语法高亮 + 光标对齐 |
| 预览渲染 | `<script type="text/plain">` 代码抽取 → `<style>` 注入 iframe | 改一行 CSS 立刻生效 |
| Tab 切换 | `data-file` 属性识别 HTML / CSS / JS | 一个实验台多文件切换编辑 |
| 搜索 | 离线索引 `search-index.js` + 关键词正则高亮 | `file://` 协议也能用 |
| 导航/侧边栏 | DOM 动态渲染，资源数据驱动 | 新增课时只需改 `learn.js` 的数据数组 |

## 🛠️ 自定义

### 给某节课添加"扩展阅读"链接

打开 `学习路线/assets/learn.js`，找到 `RES_LESSON` 对象，在对应课时数组里追加一条：

```javascript
"05-Flex弹性布局.html": [
    // ...原有链接...
    {
        n: "抖音 · Flex 讲解视频",          // 标题
        d: "配套视频课程",                   // 描述
        u: "https://v.douyin.com/SH3xUFjilTw/",  // 链接
        c: "#FE2C55",                        // 标签颜色（品牌色）
        t: "抖音"                             // 标签文字
    }
]
```

### 品牌色速查

| 平台 | 品牌色 | 标签 |
|------|--------|------|
| MDN | `#4A5568` | MDN |
| CSS-Tricks | `#B8552F` | CT |
| 菜鸟教程 | `#5F9A50` | 菜鸟 |
| B 站 | `#00A1D6` | B 站 |
| 抖音 | `#FE2C55` | 抖音 |

### 重建搜索索引

新增/修改课时后，运行：

```cmd
cd /d "d:\ProGramming\【我的前端学习】\2026新前端" && python build_search_index.py
```

### 运行回归测试

```cmd
cd /d "d:\ProGramming\【我的前端学习】\2026新前端" && python regress_all.py
```
