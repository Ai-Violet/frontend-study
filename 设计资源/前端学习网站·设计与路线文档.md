## 一、设计系统「learn 体系」

学习站全站共用一套设计令牌与交互脚本，页面只写内容，导航 / 抽屉 / 侧栏 / 翻页 / 代码实验台全部由脚本数据驱动生成。

### 1.1 设计令牌（`assets/learn.css`）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#FAF5EC` | 暖白页面底色 |
| `--accent` | `#B8552F` | 赭橙单点强调色（章节号、激活态、边框） |
| `--accent-deep` | `#9A4423` | 强调色之深 |
| `--ink / --ink-2 / --ink-3` | `#2B251D / #574D40 / #8B7E6C` | 三级文字 |
| `--line / --line-2` | `#EAE0CD / #DFD2BA` | 分隔线 |
| `--green / --amber` | `#5F7F52 / #B07A2A` | 语义点缀（成功 / 提醒） |
| `--font-ui` | PingFang / 雅黑 / Noto Sans 等 | 界面字体 |
| `--font-code` | **JetBrains Mono**（Google Fonts 加载）→ Cascadia/Consolas 兜底 | 代码 / 单字段字体 |
| 圆角体系 | 卡片 `var(--r-card)=14px`、控件 `var(--r-ctrl)=10px`、按钮全圆角 | 层次化圆角 |

背景氛围：`body::before` 呼吸径向渐变（14s 循环）+ `body::after` 44px 细网格。

### 1.2 版式（宽幅自适应）

- 内容列 `.lx-article`：`max-width:1920px`，左右留白 `clamp(24px, 11vw, 176px)`（≈ 4 个背景网格）。
- 代码实验台 `.lab`：`min(1500px, 100vw − 2×留白)`（≈ 2 个网格），比正文更宽，突出“实操区”。
- 翻页栏 `.lx-pager` 与正文同宽对齐。
- `≤900px` 移动端：实验台上下堆叠单列，正文留白收窄，自动适配。

### 1.3 核心组件契约

| 组件 | 类名 | 说明 |
| --- | --- | --- |
| 页面骨架 | `<body data-page="章/课.html">` | 脚本据此定位导航 |
| 顶部导航 / 抽屉 | `.lx-nav` / `.lx-drawer`（课程大纲，4 章） | learn.js 渲染 |
| 本页大纲 | `.lx-toc` | h2 自动编号 + 滚动高亮 |
| 扩展阅读 | `.lx-side`（RES_LESSON 本课相关 + 常备站点） | 外站 favicon 三级回退 |
| 上下课翻页 | `.lx-pager` | 数据驱动 |
| 实时实验台 | `.lab[data-lang]` + `template.lab-html` + `script.lab-code` | mac 三栏 + 行号 + 4 主题 + 拖拽分屏 + 350ms 实时预览 |
| 静态代码块 | `.lx-codeblock[data-lang]` + `script.lab-code` | mac 栏 + 高亮 + 复制 |
| 内容类名 | `lx-crumb / h1>.h-no / lx-lead / lx-chip / section>h2 / lx-table / lx-tip / lx-warn / lx-note / lx-grid>lx-card` | 统一排版 |

### 1.4 数据源（`assets/learn.js`）

- `COURSE`：4 章 × 课时与人列（含每章 `index` 目录页），决定抽屉导航与翻页。
- `RES_LESSON`：按文件名索引的“本课相关”外站资源；无匹配则只显示“常备站点”。


**课时增删只需改 `COURSE`/`RES_LESSON`，页面导航、侧栏、翻页全自动同步。**
