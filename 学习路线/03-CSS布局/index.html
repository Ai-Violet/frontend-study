本章你将学会

  • 看懂浏览器默认的文档流规则，知道块级与行内元素如何自然排列
  • 用 float 做文字环绕，理解其三特性与高度塌陷，以及 clearfix 修复法
  • 用 position 五种取值精确「钉住」任意元素，掌握参照物链与 z-index 层叠规则
  • 用 overflow 收场溢出内容，熟练写出单行 / 多行省略号
  • 用 Flex 处理一维排队，用 Grid 处理二维铺格，直接背下实战四大配方
  • 拿到一个布局需求，能判断该用哪种手段、各属性取哪些值
