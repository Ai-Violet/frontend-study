# 前端练习场 · 设计文档（互动练习.html）

> 一个离线零依赖的 VSCode 风网页代码编辑器，把课程里学到的 HTML / CSS / JS
> 放进真 IDE 的肌肉记忆里练手。

---

## 一、定位

- **论点**：不是"长得像编辑器的网页"，而是把 VSCode 的肌肉记忆搬进浏览器——
  IntelliSense 弹层、双标签自动闭合、Emmet 缩写、命令面板、查找替换。
- **目标用户**：学完章节的学生，需要一个像真 IDE 一样的练习场。
- **运行形态**：纯静态页面，零构建、零外部依赖（字体本地化，无任何 CDN），
  所有状态存 localStorage，刷新不丢。

## 二、文件构成

| 文件 | 体积 | 职责 |
|---|---|---|
| `互动练习.html` | ~10KB | 骨架：标题栏/活动栏/侧栏/编辑器/预览/状态栏/命令面板/查找栏 |
| `assets/ide-data.js` | ~70KB | 数据层：补全词库（标签/属性/属性值/CSS/JS）+ 4 章 25 个课程示例 |
| `assets/ide.js` | ~90KB | 行为层：高亮、补全、自动闭合、Emmet、查找、预览、持久化 |
| `assets/ide.css` | ~32KB | 视觉层：5 主题变量、IDE 布局、弹层、响应式 |

## 三、布局架构（自上而下）

```
┌ 标题栏 .tb ── 品牌 / 菜单 / 命令面板按钮 / 红绿灯 ┐
├ .ide-body ── 横向 flex ──────────────────────┤
│ │活动栏 .ab│侧栏 .sb│拖柄│编辑器 .ed│拖柄│预览 .pv│ │
├ 状态栏 .st ── 语言 / 行,列 / 主题 / 保存状态 ──┤
└ 控制台 .panel（Ctrl+J 折叠）──────────────────┘
```

- **活动栏**：资源管理器 / 章节示例 / 复习示例（带数字徽标）/ 主题 / 帮助。
- **编辑器**：行号槽 + 语法高亮层（`pre#hl > code`）+ 透明 `textarea#src` 叠加 +
  查找高亮层 `#find-layer` + minimap 画布。四层通过 `syncScroll` 同步滚动。
- **预览**：iframe `srcdoc` 拼装（index.html + style.css 注入 `<style>` + script.js
  注入 `<script>`），防抖 600ms 自动运行；设备宽度切换（手机/平板/全宽）。
- **响应式**（≤940px）：编辑器 54% / 预览 46% 纵向堆叠，minimap 隐藏，
  标签页宽度压缩；700px 下整页无横向溢出。

## 四、主题系统（5 套）

`body[data-theme]` 驱动全部 CSS 变量（约 40 个/主题）：面板色阶 `--p0/p1/p2`、
分割线 `--ln`、强调色 `--ac`、语法色 `--t-tag/attr/str/com/kw/num/...`、
选区 `--sel`、呼吸渐变气泡 `--b1/b2/b3`、网格色 `--grid-c`。

| 主题 | 基调 | 特色 |
|---|---|---|
| Dark+ | VSCode 经典 #1e1e1e | 默认，最接近真 VSCode |
| Light | 暖白纸张 #faf5ec | 站点赭橙血脉在此显影（--ac #b8552f） |
| Midnight | 深海蓝 #0b1526 | 冰蓝强调 #4cc2ff |
| Cosmic | 星云紫 #171322 | 薰衣草强调 #a78bfa |
| Monokai | 暗橄榄 #272822 | 经典黄绿橙 |

- **呼吸渐变背景**：3 组低透明度径向渐变气泡，60–90s 错相位 `animation` 缓慢漂移。
- **网格动画背景**：`--grid-c` 极低透明度网格线，随主题变色。
- 主题选择持久化在 `lxide.theme`；minimap 会按主题重绘。

## 五、语法高亮

单趟手写词法分析（无外部库）：按语言分支产出 `[类名, 文本]` token 流，
逐行包成 `.cl`（当前行 `.cur` 高亮），缩进空格包 `.ind` 显示缩进参考线。
HTML 内嵌 `<style>` / `<script>` 区段自动切换 CSS / JS 规则。
高亮层与 textarea 的 font-family / font-size / line-height / padding 严格一致
（曾因全局 `code` 徽章规则叠加导致 8px 光标错位，教训记录在项目记忆）。

## 六、智能补全（IntelliSense）

- **语言上下文** `langAtCursor()`：当前文件 lang；html 文件内再按光标前的
  `<style` / `<script` 开闭位置判断 css / js 区段。
- **触发**：input 事件自动触发；`Ctrl+空格` 强制触发（manual 模式放宽门槛）。
- **候选分支**（`gatherSuggestions`，按优先级短路）：
  - HTML：实体 `&`、闭标签 `</`、开标签 `<x`、标签内属性、`="` 后属性值、
    正文中 ≥2 字母的常用标签快速提示；
  - CSS：块内属性名、冒号后取值、块外 `:` 伪类、`@` 规则；
  - JS：`.` 成员、字母词（关键字 / 全局对象 / 代码片段）。
- **排序** `filterItems`：精确(0) > 前缀(1) > 包含(2) > 子序列(3)，同级按 pr。
- **接受**：Tab / Enter。标签项生成开闭对并把光标落在中间；代码片段用 `¦`
  光标锚点标记。↑↓ 选择，Esc 关闭，PageUp/Down 翻页。

## 七、自动配对与标签闭合

- 括号/引号：输入开符自动补闭符；有选区时包裹；输入与右侧相同的闭符则跳过
  （type-over）；Backspace 删除成对。
- **HTML 开标签闭合**：输入 `>` 时按正则回看最近的开标签，插入 `></tag>` 并把
  光标回退到中间。
  > 2026-09-14 修复：原正则属性部分 `[^>"']` 可吞掉换行与后续 `<`，
  > 导致 buffer 里更早的未闭合碎片（如残留的 `<di`）被误当目标，闭合出
  > `</di>`。修复为 `[^>"'\n<]`，不允许跨行、不允许吞 `<`。
  > 同款正则的 Enter 缩进判断一并修复。
- **`</` 闭合**：输入 `/` 时用 `unclosedTags` 栈算出最近未闭合标签自动补全。
- Enter：按上一行缩进 + 父标签层级自动缩进；`<div>|</div>` 之间回车生成
  双行缩进骨架。

## 八、Emmet（HTML）

递归下降解析器：支持 `.class` `#id` `[attr=val]` 子代 `>` 相邻 `+` 乘法 `*n`
文本 `{...}` 分组 `()`。例：`.box>p*2` + Tab 展开：

```html
<div class="box">
  <p></p>
  <p></p>
</div>
```

已知限制：**仅 HTML 有 Emmet，CSS 缩写未实现**（见"已知限制"）。

## 九、查找替换（Ctrl+F / Ctrl+H）

`#find-layer` 覆盖层按行列换算渲染命中矩形（当前项加深），Enter/Shift+Enter
跳转，替换/全部替换直接改写 buffer 并联动撤销栈。

## 十、命令面板（Ctrl+K）

聚合命令：运行动作（新建/运行/暂停实时/保存/切栏…）+ 5 主题 + 25 示例 +
全部复习示例。子序列模糊过滤，↑↓ Enter 执行。

## 十一、持久化（localStorage，前缀 `lxide.`）

| 键 | 内容 |
|---|---|
| `draft` | 三文件内容 + 来源示例 id，input 后 300ms 防抖落盘，`beforeunload` 兜底 |
| `reviews` | 复习示例列表（id/名称/时间戳/三文件），Ctrl+S 保存，同名覆盖 |
| `theme` | 当前主题 id |
| `progress` | 每个示例练习目标的勾选状态 |

## 十三、已知限制

1. **CSS Emmet 未实现**：Tab 在 CSS 文件里只做缩进（VSCode 有 `w100p` 类缩写）。
2. **JS 高亮较简**：正则/模板字符串部分场景可能着色不精确。
3. 查找高亮在超长行 + 横向滚动组合下可能有 1–2px 偏差。
4. minimap 只做密度示意，不支持点击跳转。
5. 无多光标、无代码格式化（beautify）。
